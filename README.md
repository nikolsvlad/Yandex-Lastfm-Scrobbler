# Яндекс Музыка → Last.fm Scrobbler

Chrome-расширение для автоматического скроблинга треков из Яндекс Музыки на Last.fm.

## Установка

### 1. Загрузить расширение в Chrome

1. Открой Chrome и перейди на `chrome://extensions/`
2. Включи **«Режим разработчика»** (правый верхний угол)
3. Нажми **«Загрузить распакованное расширение»**
4. Выбери папку `yandex-lastfm-scrobbler`

### 2. Получить API-ключ Last.fm

1. Перейди на https://www.last.fm/api/account/create
2. Войди в аккаунт Last.fm
3. Заполни форму (название и описание — любые)
4. Скопируй **API key** и **Shared secret**

### 3. Настроить расширение

1. Нажми на иконку расширения в Chrome
2. Вставь **API Key** и **Shared Secret**
3. Нажми «Продолжить» — откроется страница авторизации Last.fm
4. Нажми «Разрешить доступ» на Last.fm
5. Вернись в popup и нажми «Я разрешил доступ ✓»

Готово! Открой Яндекс Музыку и начни слушать.

## Как работает

- **Content Script** отслеживает изменения DOM на music.yandex.ru и определяет текущий трек
- **Background Worker** отправляет запросы к Last.fm API:
  - `track.updateNowPlaying` — сразу при смене трека
  - `track.scrobble` — через 50% длительности трека (или 4 минуты максимум)
- Все скроблы сохраняются в лог (последние 50)

## Иконки

Папка `icons/` содержит PNG-файлы: `icon16.png`, `icon48.png`, `icon128.png`.
Если иконок нет — Chrome покажет заглушку, но расширение работает нормально.

## Совместимость

Тестировалось на Chrome 120+. Поддерживаются домены:
- `music.yandex.ru`
- `music.yandex.com`
