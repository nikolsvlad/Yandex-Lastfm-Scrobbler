# Яндекс Музыка → Last.fm Scrobbler

Chrome-расширение для автоматического скроблинга треков из Яндекс Музыки на Last.fm.

## Установка

1. Открой Chrome и перейди на `chrome://extensions/`
2. Включи **«Режим разработчика»** (правый верхний угол)
3. Нажми **«Загрузить распакованное расширение»**
4. Выбери папку с расширением
